## 三、三个功能的调用映射（功能1/2 共用入口，只差高度）

```cpp
using namespace cube_dbg;

// 前置：robot::catch_ground_cube.requestPrepare(); requestRun();  （Subsystem 进入 Running）

// 功能1：贴地放两个（车在 L1 放塔基，或车在 L2 放 L2 方块）
//        高度 = 贴地释放高度（地面高度 + 爪间隙），见待填参数表
putAt(put_ground_height_mm, PUT_RELEASE_BOTH);

// 功能2：抬升到目标高度后放两个（车在 L1 放 L2 方块）—— 与功能1 同一入口
putAt(l2_place_height_mm, PUT_RELEASE_BOTH);

// 功能3（接力）：对手塔基已就位但未放中段时，抬升到塔基顶面高度后只放一个中段，
//               另一只爪保持夹紧（L1公共区/L2 共建塔合法，中段得分归放置方）
putAt(relay_height_mm, PUT_RELEASE_VALVE1_ONLY);   // 或 PUT_RELEASE_VALVE2_ONLY

// 功能4（实验性，不一定能用——规则风险见下）：移除对方"未正确放置"的方块
//   步骤：startGrab(GrabSelection::VALVE1_ONLY) 在高度夹住 → moveToHeightMm 抬升 →
//         底盘转移 → putAt(丢弃高度, PUT_RELEASE_VALVE1_ONLY) 释放
//   【规则风险】规则 7.2：故意移除/移动/干扰"已正确放置"的对方塔基/中段 = 取消比赛资格；
//   规则 V2 3.5.5 只允许移动"未正确放置"的，是否"正确"由裁判认定，赛前必须对照规则原文确认

// 流程监控（非阻塞）：轮询直到 != busy
while (robot::catch_ground_cube.put().busy()) { /* 或挂到 HFSM 状态里 */ }
// 结果：put().isDone() / put().isFailed()；失败后可 putCancel() + 重新 startPut
```

## 四、放置状态机（PutGroundCube::State）

```
IDLE →(start) LIFTING →(到位) STABLE →(稳定保持) RELEASING →(脱离等待) DONE
  ↑__________________________cancel/完成后 reset__________________________|
  任一步 sync_fault 或升降超时 → FAILED（停在当时高度，cancel 后重发）
```

- LIFTING/STABLE 每帧重发目标高度，外部手动 jog 干扰最多导致超时 FAILED，不会损坏机构。
- cancel 不动阀、不改目标：中断时机构保持现状，撤离决策留给上层。

## 五、待填参数表（【待确认】项装车试车时逐项落实）

| 参数 | 位置 | 含义 | 建议初值 |
|---|---|---|---|
| `CGC_VALVE_CLAMPED` | catch_ground_cube.hpp 宏区 | 夹紧对应的阀电平（true=得电夹紧） | 装车后验证，反了只改这一处 |
| 阀号↔上/下爪 | put 调用处 | VALVE1/2 哪个是上爪 | 机械确认 |
| `config.lift_after_grab_mm` | catch Config | 抓取后自动抬升量，0=关闭 | 10~30，以方块离地为准 |
| `config.grab_settle_ms` | catch Config | 合爪后锁定等待 | 80（> valve_pulse_ms） |
| `put config.arrive_tolerance_mm` | PutGroundCube::Config | 到位容差 | 2.0 |
| `put config.stable_time_ms` | 同上 | 到位稳定保持 | 100 |
| `put config.release_settle_ms` | 同上 | 开爪后脱离等待 | 150 |
| `put config.lift_timeout_ms` | 同上 | 单步升降超时 | 3000 |
| 贴地释放高度 | 业务层 | 功能1 的 height_mm 实参 | ground_clearance_mm + 爪间隙，实测 |
| L2 放置高度 | 业务层 | 功能2/3 的 height_mm 实参 | 按场地 L1/L2 高差 + 爪间距算，实测 |

## 六、注意事项

1. 放置与抓取共用同一套电机/阀：**同一时刻只跑一个流程**（put busy 时再 startGrab
   会互相改目标；上层 HFSM 负责互斥，本层不强制）。
2. 脉冲阀模式下开/合爪都会自动等脉宽，LIFTING→STABLE 的 stable_time_ms 已覆盖脉宽时间，
   无需额外延时。
3. `CubeStatus` 结构体新增 `grab_state` 字段，旧调试代码若 aggregate 初始化该结构体需补字段。
4. 功能4（实验性，不一定能用）完整流程 = startGrab(VALVEx_ONLY) 在高度夹住对方"未正确
   放置"方块 → 抬升移走 → putAt 释放。规则风险已写入代码注释与功能4 段落（7.2 取消资格条款）。
